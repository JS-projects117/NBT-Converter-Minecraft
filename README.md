NBT-Converter-Minecraft

Summary:
  Takes an input of a minecraft .nbt file which are used to store structure information to enable saving and spawning structures in game>.
  This program aims to solve the inability to spawn structures using modded blocks into newer unsupported versions of minecraft by replacing all blocks in the nbt save with vanilla minecraft blocks.

A generation key is generated allowing the user to know understand blocks replaced and their replacers in a key pair format.

THis was a personal utility program I used while making minecraft mods to allow easier transfer of structures to new versions of minecraft.
